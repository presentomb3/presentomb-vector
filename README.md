# presentomb vector

`presentomb vector` is a stereo vectorscope for real-time phase, width, balance, and headroom monitoring.

It displays incoming stereo audio as a CRT-style XY oscilloscope with adjustable phosphor color, glow, persistence, gain, beam width, and intensity.

## Downloads

Download current builds from [GitHub Releases](https://github.com/presentomb3/presentomb-vector/releases).

- Windows VST3
- Windows installer with optional standalone app
- Universal macOS VST3 for Apple Silicon and Intel
- Universal macOS standalone app for Apple Silicon and Intel


## Install

### Windows

Run the installer, or copy the VST3 bundle to:

```text
C:\Program Files\Common Files\VST3
```

### macOS

Copy the VST3 bundle to:

```text
~/Library/Audio/Plug-Ins/VST3
```

Move the standalone app to `Applications` if wanted.
